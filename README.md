# Carta para mi best friend ❤️

Una carta web romántica y floral hecha con HTML, CSS y JavaScript, lista para publicarse gratis con GitHub Pages.

## Qué incluye
- Pantalla de bienvenida con el botón **Para mi best friend**.
- Lirio rojo ilustrado en SVG.
- Título que se escribe letra por letra.
- Carta con párrafos que aparecen gradualmente.
- Pequeñas flores que flotan mientras se lee.
- Música instrumental suave sintetizada en el navegador (no requiere archivo de audio ni descarga externa).
- Diseño adaptable a teléfonos y computadoras.

## Publicar en GitHub Pages
1. Entra en https://github.com/new e inicia sesión.
2. Crea un repositorio llamado `carta-best-friend`.
3. Selecciona **Public** y crea el repositorio.
4. Descomprime el ZIP en tu dispositivo.
5. Dentro del repositorio, selecciona **Add file → Upload files**.
6. Sube `index.html`, `style.css`, `script.js` y `README.md` a la raíz del repositorio.
7. Pulsa **Commit changes**.
8. Abre **Settings → Pages**.
9. En **Build and deployment**, selecciona **Deploy from a branch**.
10. Elige la rama `main` y la carpeta `/(root)`, luego pulsa **Save**.
11. Espera unos minutos. GitHub mostrará el enlace público, normalmente con este formato:
   `https://TU-USUARIO.github.io/carta-best-friend/`

## Notas
- La música empieza después de pulsar el botón inicial, porque los navegadores móviles requieren una interacción del usuario para permitir audio.
- La música se genera con Web Audio API; es una melodía original sencilla, sin un archivo MP3 externo.
- Para cambiar el texto, edita el contenido de `index.html`.
- No cambies los nombres de los archivos principales.
